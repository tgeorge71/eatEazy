# eatEazy

Decision-fatigue reducer for "what's for dinner" — state your constraints once, get 3 meal
options on demand, and turn the pick into a grocery list.

A React Native (Expo) app with a small FastAPI backend that calls Claude to generate suggestions.

## Backend setup

The app talks to a local FastAPI server (`main.py`) that holds the Anthropic API key —
suggestions are never generated by calling Anthropic directly from the app.

```
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then add your ANTHROPIC_API_KEY
uvicorn main:app --reload --port 8000
```

`GET /health` should return `{"status": "ok"}`. Until `ANTHROPIC_API_KEY` is set, `/suggestions`
returns a clear 503 rather than mock data.

## Frontend setup

Requires [Node.js](https://nodejs.org/) and npm.

```
npm install
npm start
```

Then choose a platform:

```
npm run ios      # iOS simulator (macOS + Xcode)
npm run android   # Android emulator
npm run web       # Browser
```

Or scan the QR code from `npm start` with the [Expo Go](https://expo.dev/client) app on your phone.

The app reads the backend URL from `EXPO_PUBLIC_API_URL` in `.env` (see `.env.example`). The
default (`http://localhost:8000`) works for the web target and simulators; on a physical device
via Expo Go, point it at your machine's LAN IP instead, since the phone can't resolve `localhost`
as your computer.

## Project structure

```
.
├── App.tsx                 # App root — providers + navigation
├── main.py                  # FastAPI backend (Anthropic proxy)
├── requirements.txt          # Backend dependencies
├── index.ts                  # Frontend entry point
├── app.json                   # Expo config
├── assets/                    # Icons and splash screen
└── src/
    ├── api/                    # Backend API client
    ├── components/              # Reusable UI components
    ├── config.ts                 # API base URL
    ├── context/                   # Constraints + in-session plan state
    ├── navigation/                 # Screen routing
    ├── screens/                     # App screens
    ├── types/                        # Shared types
    └── utils/                         # Grocery list dedupe logic
```
